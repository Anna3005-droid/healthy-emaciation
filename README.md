# Марафон Healthy Weight Loss

Трекер марафону схуднення: 35 днів, 24 тренування (2 дні тренування, 1 день відпочинку),
вода, кроки, харчування і книга рецептів із порціями під 1300, 1450, 1600 і 1900 ккал.

Звичайний сайт без збірки: `index.html`, `styles.css`, `app.js`, `recipes.json`.
Учасниці входять зі своєю поштою і паролем, тож відмітки зберігаються в акаунті
й видно з будь-якого телефона чи комп'ютера. Кабінету організаторки немає.
Вхід і дані зберігаються в Supabase, сайт публікує Vercel.

## Supabase (вхід і база)
1. Зареєструйтеся на https://supabase.com і створіть проєкт (New project). Регіон: Frankfurt (Central EU).
2. SQL Editor → New query → вставте весь файл `supabase/schema.sql` → Run.
3. Authentication → Sign In / Providers → Email: вимкніть **Confirm email** і збережіть.
   Інакше кожній учасниці прийде лист, а безкоштовна пошта Supabase надсилає лише кілька листів на годину.
4. Authentication → URL Configuration → **Site URL** = `https://healthy-emaciation.vercel.app`. Це для листів «Забули пароль».
5. Project Settings → API: скопіюйте **Project URL** і **Publishable key** і впишіть їх у `config.js`.

## Публікація на Vercel
1. Увійдіть на https://vercel.com через GitHub.
2. Add New → Project → виберіть цей репозиторій → Deploy. Налаштування міняти не потрібно.
3. Скопіюйте адресу сайту, наприклад `https://healthy-emaciation.vercel.app`, і надсилайте її учасницям.

Кожна зміна, надіслана на GitHub, Vercel публікує сам приблизно за хвилину.

## Що де міняти
- Кількість днів, тренувань і комплексів, об'єм склянки: на початку `app.js`
  (`DAYS`, `WORKOUTS`, `COMPLEXES`, `GLASS`).
- Графік тренувань: функція `isRest` в `app.js` (зараз кожен третій день вихідний).
- Рецепти: `recipes.json`. Кожен рецепт: `t` назва, `s` розділ, `m` прийом їжі,
  `p` порції `[калораж, вага]`, `ing` інгредієнти, `st` кроки приготування, `n` примітки.
- Лого, обкладинка, іконки: папки `img` і `icons`.

## Важливо для учасниць
- Входити треба з тією самою поштою на всіх пристроях.
- Сайт можна додати на головний екран телефона, і він відкриватиметься як застосунок:
  iPhone: Safari → «Поділитися» → «На екран Додому»;
  Android: Chrome → меню → «Додати на головний екран».
